# security

assembly reads design files from links agents give it, takes photos from anyone with a manual's link, and holds the api keys people connect for photo checks, so bugs in any of that matter.

if you find a security issue, please report it privately through [github security advisories](https://github.com/luiginotmario/assembly/security/advisories/new) instead of opening a public issue. you'll hear back as soon as possible.
